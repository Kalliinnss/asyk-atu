# Асық ату — цифровая версия

2D-игра (HTML5 Canvas + JavaScript) по мотивам казахской игры на меткость. Для новичков и семей: есть интерактивное обучение, управление мышью и касанием.

## Правила
Тяни сақа назад, как рогатку, и отпусти: направление и сила зависят от натяжения. Асык, вышедший за красную рамку поля, — **+10**. Комбо (2+ за бросок) — **+5** за каждый лишний. Очистил поле — неиспользованные броски переходят на следующий этап; на последнем этапе за каждый оставшийся бросок **+10**. 3 этапа (6 / 6 / 7 бросков). 90+ очков — победа, 140+ — «Шебер».
**Авторские дополнения:** комбо, бонус за чистое поле, три расстановки, звания, обучение, звук и тряска при ударе.

## Возможности
- Собственная физика кругов: упругие столкновения с учётом масс, трение; каждый асык засчитывается один раз.
- Подсказки для новичка на первом этапе: анимированный жест и подписи (при первом запуске и по кнопке «Играть с подсказками»).
- Сохранение раунда между бросками этапов, рекорд и история результатов (localStorage).
- Авторизация (email + пароль), личный рекорд, история и прогресс с доступом с любого устройства — Supabase (Auth + Postgres, Row Level Security).

## Запуск и настройка облака
1. Откройте `index.html` (или выложите на GitHub Pages / Netlify). Без настройки игра работает в локальном режиме.
2. Создайте проект на supabase.com, выполните `schema.sql` в SQL Editor.
3. Authentication → Providers → Email: отключите «Confirm email» (для тестового доступа).
4. Project Settings → API: впишите Project URL и anon key в `SB_URL` и `SB_KEY` в начале блока «Облако» в `index.html`. anon key публичный, доступ защищён политиками RLS.
5. Тестовый аккаунт: создайте и укажите в форме сдачи.

## Технологии и AI
HTML5 Canvas, JavaScript, Supabase JS v2 (CDN). Код написан с помощью Claude (Anthropic) и проверен автором. Шаблоны не использованы.

## Ограничения
Нет мультиплеера и турниров; столкновения упрощены до кругов; без настройки Supabase облачные функции отключены.
